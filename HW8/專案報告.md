# GreenLedger：中小微企業碳盤查與排碳成本核算微服務系統
## 專案成果、商業/使用價值與技術交付總整理

## 一、 專案核心主題與價值定位 (Value Proposition)

### 1. 使用價值 (Usage Value：精準解決剛性痛點)
* **供應鏈合規去焦慮化**：國際品牌與半導體供應鏈（如 TSMC、Apple 供應鏈規範）強制要求二、三階中小供應商提交符合 ISO 14064-1 規範之盤查數據。本系統將複雜的活動係數換算透明化，廠務與會計人員輸入電費單度數、公務車燃油公升數即可完成合規計算。
* **降低人為與版本錯誤**：傳統 Excel 填報常因公式毀損或使用過期排放係數而失真；系統內嵌台灣環境部氣候變遷署與經濟部能源署官方最新係數，確保盤查數值精準無虞。
* **自身即使用者**：任何擁有固定辦公室、廠房、運輸車隊的營運團隊，每月皆能以本系統自動維護自身企業的能源消耗與溫室氣體數據檔案。

### 2. 商業價值 (Commercial Value：獲利模式與接案藍圖)
* **單案客製化交付（短期現金流接案）**：
  * 中小工廠與傳統製造業專屬碳盤查填報系統，包含廠區環境部署與教育訓練，單案接案交付行情約 **NT$ 50,000 ~ 120,000**。
* **Micro-SaaS 雲端訂閱制（長期經常性收入 ARR）**：
  * **標準版（NT$ 890 / 月）**：單廠區基本盤查、範疇一與範疇二分流、即時活動數據庫存。
  * **進階專業版（NT$ 2,490 / 月）**：多廠區/多營業所核算、台灣碳費（NT$300 與 NT$500/噸）暴險財務試算、一鍵匯出 ISO 14064-1 審查 CSV 與第三方認證報表。
* **ESG 淨零顧問衍生效益**：軟體系統作為前端獲客管道，後續可進一步衍生節能設備汰換、太陽光電建置及自願減量額度抵換等高毛利專案。

## 二、 系統完成架構與技術交付清單

### 1. 微服務架構 (Microservices Architecture)
本系統透過 `docker-compose.yml` 編排三大獨立微服務，並以自訂虛擬橋接網路 (`app-net`) 進行通訊隔離：
* **Nginx (Reverse Proxy & Web Server)**：對外監聽 Port 80，直接託管靜態前端頁面，並將所有 `/api/` 路由精準反向代理至後端應用服務，保障內部架構安全性。
* **Backend API (Python FastAPI / Rust)**：提供高效能非同步 API，負責活動數據校驗、排放量計算公式執行、與碳費暴險財務試算。
* **Database (PostgreSQL 16 Alpine / SQLite)**：具備 Docker Volume 持久化掛載機制，確保重啟容器後數據資料完整保留。

### 2. 軟體測試金字塔體系 (3-Tier Testing Pyramid)
落實從核心領域邏輯到完整前端渲染的完整測試防護網：

| 測試層級 | 測試標的 | 採用技術與工具 | 驗證重點 |
| :--- | :--- | :--- | :--- |
| **單元測試 (Unit Test)** | 後端核心商業邏輯 | Rust 原生測試框架 (`cargo test --lib`) | 輸入欄位清洗、長度限制、數值非負校驗、空標題阻擋 |
| **系統測試 (System API)** | Web API 整合流程 | Axum 測試管線 + Tower (`cargo test --test`) | HTTP 路由匹配、狀態碼 (200/201/400)、JSON 序列化與資料狀態變化 |
| **端到端測試 (E2E Test)** | 使用者真實瀏覽器操作 | Playwright 無頭 Chromium (`npx playwright test`) | DOM 元件選取、動態新增/刪除任務項目、錯誤提示訊息與非同步渲染 |

## 三、 排碳核算引擎與官方排放係數參考

系統核心演算法採用台灣環境部氣候變遷署與經濟部能源署最新公佈基準（單位：$tCO_2e$ / 原始單位）：

| 排放源種類 | 歸屬範疇 (Scope) | 單位 | 排放係數 ($tCO_2e$ / 單位) | 應用情境 |
| :--- | :--- | :--- | :--- | :--- |
| **外購電力 (台電)** | 範疇二 (電力間接) | 度 (kWh) | `0.000495` | 廠房辦公室電費單度數 |
| **車用汽油** | 範疇一 (移動燃燒) | 公升 (L) | `0.002263` | 公務車、業務用車加油單 |
| **車用柴油** | 範疇一 (移動燃燒) | 公升 (L) | `0.002606` | 物流大貨車、推高機柴油 |
| **天然氣** | 範疇一 (固定燃燒) | 立方公尺 ($m^3$) | `0.002090` | 廠區工業鍋爐、熱能設備 |
| **液化石油氣 (LPG)** | 範疇一 (固定燃燒) | 公斤 (kg) | `0.003010` | 桶裝瓦斯、員工餐廳烹飪 |

### 碳費財務暴險試算公式：
$$\text{範疇一總排碳} = \sum (\text{Scope 1 活動量} \times \text{對應係數})$$
$$\text{範疇二總排碳} = \sum (\text{Scope 2 活動量} \times \text{對應係數})$$
$$\text{預估碳費負擔 (NT\$)} = (\text{範疇一} + \text{範疇二}) \times \text{單位碳費費率 (NT\$ 300 或 500)}$$

## 四、 測試執行快速速查指令

```bash
# 1. 執行 Rust 商業邏輯單元測試
cargo test --lib unit_tests

# 2. 執行 Web API 系統整合測試 (避免資料競爭可加上單執行緒參數)
cargo test --test api_test -- --test-threads=1

# 3. 執行 Playwright E2E 無頭瀏覽器端到端測試
npx playwright test

# 4. 以視覺化視窗模式與互動式介面進行 E2E 除錯
npx playwright test --headed
npx playwright test --ui
```
