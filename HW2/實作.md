# 大專院校校務資訊系統專案藍圖

本專案旨在建立一個結構嚴謹且具備權限角色控管（RBAC）的校務資訊系統，類似金門大學等大專院校所使用之系統。

## 一、 系統核心模組規劃

系統包含三個主要視角（Roles）：

### 1. 學生端 (Student Portal)
* **學籍與個人資料**：基本資料、學分統計、畢業門檻查詢。
* **選課系統**：初選、加退選、課程搜尋（過濾條件）、衝堂擋修機制。
* **課表與成績**：個人專屬課表、歷年成績單、學期排名查詢。
* **各項申請**：線上請假、成績單列印申請、獎學金申請。

### 2. 教師端 (Faculty Portal)
* **課程管理**：上傳課程大綱、教材與講義管理。
* **班級管理**：線上點名、修課學生名單匯出。
* **成績登錄**：期中/期末成績輸入、成績分布圖表、平時成績計算。

### 3. 行政/教務端 (Admin/Staff Portal)
* **帳號與權限管理**：建立師生帳號、重置密碼、設定系統開放時間。
* **排課與教室管理**：系所開課設定、教室借用與排程。
* **公告系統**：發布全校性或特定系所的教務公告。

---

## 二、 推薦技術堆疊 (Tech Stack)

| 領域 | 推薦技術 | 原因說明 |
| :--- | :--- | :--- |
| **前端** | React (Next.js) 或 Vue 3 + TypeScript | 適合構建複雜表單，TS 減少錯誤。 |
| **UI 組件庫**| Ant Design 或 Material-UI (MUI) | 內建資料表與表單元件，適合後台系統。 |
| **後端** | Java (Spring Boot) 或 Node.js (NestJS)| 企業與學校常見選擇，具備極佳安全性與穩定性。 |
| **資料庫** | PostgreSQL | 處理複雜關聯查詢與資料完整性極佳。 |
| **身分驗證** | JWT + Redis | 實作登入驗證、Token 過期機制。 |

---

## 三、 核心資料庫設計概念 (Schema 雛形)

1. **Users (使用者表)**: `id`, `username`, `password_hash`, `role`, `department_id`
2. **Courses (課程表)**: `id`, `course_code`, `course_name`, `teacher_id`, `credits`, `capacity`, `schedule`
3. **Enrollments (選課紀錄表)**: `id`, `student_id`, `course_id`, `status`, `semester`
4. **Grades (成績表)**: `id`, `enrollment_id`, `midterm_score`, `final_score`, `total_score`, `grade`

---

## 四、 實作步驟建議

1. **環境建置與架構初始化**：設定前後端框架、Git 與資料庫。
2. **建置身分驗證系統**：實作登入 API 與 JWT 權限。
3. **開發 CRUD 基礎功能**：完成管理員新增師生與課程的功能。
4. **實作核心業務邏輯**：選課系統（處理併發與 Transaction）。
5. **前端圖表與報表**：課表視覺化與成績單匯出。
